## What was completed this session

### 1. HOV_TRACE OAT calibration fix ✅
All four hover chart trace overlays were placing the OAT entry point 5°C too cold. Root cause: the OAT y-axis label "0°C" sits 16px below its gridline at y=981; y=612 (the +35°C gridline) was misidentified as +40°C, shifting every trace one step cold.

**Fix:** Reverted all four `HOV_TRACE_*` constants in `app.js` to original values. Confirmed by crew — traces now dead accurate across all four charts.

| Constant | yOAT40 | yOATneg45 |
|---|---|---|
| HOV_TRACE_MAX_CONT_AI_OFF | 559 | 1456 |
| HOV_TRACE_30MIN_AI_OFF | 561 | 1457 |
| HOV_TRACE_MAX_CONT_AI_ON | 565 | 1463 |
| HOV_TRACE_30MIN_AI_ON | 559 | 1456 |

**Do not alter these values.** The +40°C gridline sits above the visible panel border — this is correct.

**Data accuracy confirmed:** Fig 4-21 validated against six paper readings on PA=4000 curve — all within ±30kg. Config.js chart data is correct.

## What's new note — convention for future sessions

The splash page note box gives crews one or two lines explaining what changed. Claude writes this at the end of each session. Guidelines:

| Version type | Scope | Detail level |
|---|---|---|
| **1.6.x** | Bug fix / UI tweak / minor improvement | One concise sentence. What was wrong, what's better. No technical detail. |
| **1.7.0** | New feature or new tab | Two to three sentences. What the feature does, which tab, any operational note. |
| **2.0.0** | Change to underlying math or chart data | Full paragraph. What changed, which charts/tabs affected, validation performed, why crew should re-familiarise. |

Update the note text in `index.html` inside `.splash__whatsnew` — the version label is auto-populated, only the description text changes.
