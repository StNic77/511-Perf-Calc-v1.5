## Versioning convention
- **1.6.x** — bug fixes, UI tweaks, minor improvements
- **1.7.0** — new feature or new tab
- **2.0.0** — change to underlying math or chart data

**Push workflow:**
1. Make code changes
2. Bump `CACHE_VERSION` in `sw.js` (e.g. `v1.6.3` → `v1.6.4`)
3. Update `version` in `config.js` to match
4. Push all changed files
5. Open app on any connection, swipe away, reopen — new version live
