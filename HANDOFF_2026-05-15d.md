## Paper reading format for next session
Provide 3–5 points per chart, spread across the usable range:

**HOGE:** `DA / AUW → Qref (%Q)`
Example: `DA=0ft, AUW=13000kg → 91.0%Q`

**TV:** `PA / OAT → TV value`
Example: `PA=3000ft, OAT=10°C → 8.5`

**HLDF:** `AUW / DA → height loss (ft)` or `min fwd reject height (ft)`
Example: `AUW=13000kg, DA=2000ft → 35ft height loss`

**SR:** `AUW / DA → max SR height (ft)`
Example: `AUW=13000kg, DA=2000ft → 40ft`

## Calibration methodology (established from HOV trace work)
- Scan PNG for strong horizontal/vertical lines to find axis bounds
- Use label cluster positions (scan left/side margin for text) to confirm which gridline = which value — **do not rely on gridline darkness alone**
- Run linear regression on 6+ measured gridline positions
- Cross-validate predicted gridline positions against paper readings
- The axis label text sits slightly offset from the gridline (e.g. 16px below for "0" on OAT axis) — account for this
- Do not change axis values without PNG measurements + paper validation

**Critical lesson from HOV trace:** The first visible gridline inside the panel border is NOT necessarily the axis maximum — it may be one step below. Always verify with label positions.
